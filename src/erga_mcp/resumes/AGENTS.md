# Resume workflow instructions

This package owns resume sources, template preservation, tailoring, bullet quality, planning,
reviewable artifacts, and cover-letter generation.

- Every claim must trace to approved evidence; never infer missing skills, impact, or metrics.
- Preserve the user's source template and validate rendered layout before accepting a proposal.
- Produce reviewable local diffs. Remote publication always requires explicit approval.
- Project discovery and Git accounting belong in `portfolio/`; MCP interaction belongs in `mcp/`.
