# Portfolio evidence instructions

This package owns project catalogue data, ranking inputs, Git and GitHub discovery, attributable
repository evidence, skill evidence, and supported metric proposals.

- Git history can establish authorship and implementation scope, not impact or adoption.
- Keep generated metric candidates review-only until the user confirms them.
- Use explicit configured roots and bounded history; never crawl a home directory implicitly.
- Resume wording and layout belong in `resumes/`; provider wire details belong in `integrations/`.
